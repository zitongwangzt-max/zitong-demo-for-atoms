# Folio · 简历建站

Folio 是一个对话式个人简历网站生成工具。粘贴现有简历或零散经历，生成网页初稿，再用对话调整内容和样式。做好的页面可以下载为 HTML，也可以发布成一个可分享的链接。

## 平台功能

| 功能 | 使用方法 |
| --- | --- |
| 整理简历 | 粘贴材料、导入 `.txt` 或 `.md`，也可以从示例开始。接入模型后，可结合目标岗位梳理经历，把需要确认的信息留在对话里。 |
| 对话改版 | 用自然语言调整全页配色，也可以单独改按钮或页脚的颜色、移动区块，或新增「荣誉获奖」等栏目。常见内容可通过「编辑资料」直接修改。 |
| 预览和代码 | 默认显示网页预览，支持桌面、手机和全屏视图。切到「代码」可在带语法高亮的 HTML 编辑器中修改、格式化和应用源码，也能点击「下载 HTML」导出。 |
| 草稿和版本 | 草稿与版本历史保存在当前浏览器，可恢复此前生成的版本。 |
| 发布和头像 | 点击「发布」→「发布当前版本」，生成 `/page/<随机标识>` 链接。点击预览中的头像可上传图片。发布者在原浏览器打开已发布页面，也可以点击头像重新上传，继续使用原来的发布链接。 |

对话里可以直接说「把整体主题换成雾霾蓝，页脚背景单独改成 `#1E293B`」或「新增荣誉获奖栏目，放在项目经历后面」。

## 本地运行

建议使用 Node.js 20 或更新版本、Python 3.10 或更新版本。Python 服务使用标准库。

```bash
git clone https://github.com/zitongwangzt-max/zitong-demo-for-atoms.git
cd zitong-demo-for-atoms
npm ci
npm run dev
```

打开 [本地工作台](http://127.0.0.1:5173)。服务默认监听 `0.0.0.0`，同一局域网内也可以用运行机器的 IP 加上 `5173` 端口访问。发布链接使用当前访问地址，通过 `127.0.0.1` 生成的链接只能在本机打开。

`5173` 已被占用时，先运行 `npm run build:editor`，再用 `python3 scripts/server.py --port 5174` 启动。

### 构建并运行

```bash
npm run build
npm run preview
```

构建结果位于 `dist/index.html`，预览服务地址为 [http://127.0.0.1:4173](http://127.0.0.1:4173)。使用自定义端口时，可运行 `python3 scripts/server.py --built --port 8080`。模型调用、发布和头像上传均由 Python 服务提供。

## 配置大模型

1. 打开右上角的「模型设置」，填写 OpenAI 兼容的 Chat Completions API 地址，例如 `https://api.openai.com/v1`，以及服务商提供的 API Token。远程 API 使用 HTTPS，本机模型接口可以使用 HTTP。
2. 点击「获取模型」，从服务商返回的列表中选择。服务商未提供模型列表接口时，可直接填写模型 ID。
3. 点击「保存设置」，再点击「测试连接」。配置后，对话会向指定的模型服务发送当前简历、近期对话和本次修改要求。

未配置模型时，可以使用本地文本整理和基础样式调整。模型的资料梳理流程采用 ASu make-resume 的素材归类、证据核对和补问方法。梳理规则和编辑指令分别保存在两个 Markdown 文件中，可以直接修改。[简历资料梳理](prompts/resume-intake.md) · [简历编辑助手](prompts/resume-assistant.md)

| 数据 | 默认存放位置 |
| --- | --- |
| 模型地址、模型 ID 和 API Token | 服务端的 `.folio/model.json`，可用 `--config` 指定文件路径。 |
| 发布页和上传的头像 | 服务端的 `.folio/pages/`。目录默认与模型配置文件同级，可用 `--pages-dir` 或 `FOLIO_PAGES_DIR` 指定。 |
| 草稿、对话和版本历史 | 当前浏览器的本地存储。 |

`.folio/` 已被 Git 忽略。API Token 应保存在服务端配置文件内。
